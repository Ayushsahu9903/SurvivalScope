🚢 SurvivalScope
A machine learning app that predicts a passenger's chance of surviving the Titanic disaster, built with scikit-learn and served through an interactive Streamlit interface.

🔗 Live app: https://survivalscope-z6yd4npcygwt2bsm9zry5y.streamlit.app

Overview
SurvivalScope trains a Random Forest classifier on the classic Titanic dataset (via seaborn) using a leak-free, production-style scikit-learn pipeline — imputation, encoding, and scaling are all bundled with the model itself, so the exact same preprocessing runs both at training time and when a user submits data through the app.

Test accuracy: ~81.6%
ROC-AUC: ~0.85
Model: Random Forest (tuned via GridSearchCV, 5-fold CV)
Features
No data leakage — train/test split happens before any imputing or encoding
Engineered features: family_size (siblings + parents/children + self) and title (derived from passenger type)
Full ColumnTransformer + Pipeline — one saved artifact (titanic_pipeline.joblib) handles all preprocessing and prediction
Hyperparameter tuning with cross-validated ROC-AUC scoring
Interactive Streamlit UI with live probability output

Setup
Clone or download this project folder.
Install dependencies:
pip install -r requirements.txt
Usage
1. Train the model
python train.py
This downloads the Titanic dataset, trains and tunes the Random Forest, prints evaluation metrics, and saves titanic_pipeline.joblib in the current folder.

2. Run the app
streamlit run app.py
Open the local URL Streamlit prints (usually http://localhost:8501), fill in passenger details, and click Predict survival to see the outcome and probability.

Model Details
Step	Technique
Numeric features (age, fare, family_size)	Median imputation + standard scaling
Categorical features (pclass, sex, embarked, title)	Most-frequent imputation + one-hot encoding
Classifier	RandomForestClassifier, tuned over n_estimators, max_depth, min_samples_leaf
Validation	5-fold cross-validation, ROC-AUC scoring
Deployment
To deploy on Streamlit Community Cloud:

Push this folder to a GitHub repo (include titanic_pipeline.joblib and requirements.txt).
Go to share.streamlit.io, connect the repo, and set app.py as the entry point.
Streamlit Cloud installs requirements.txt automatically and serves the app.
